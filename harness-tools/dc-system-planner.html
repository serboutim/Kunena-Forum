For each circuit the planner picks the smallest gauge that meets the drop limit and ampacity (after temperature and bundle derating). It then selects the next standard fuse at or above 125% of the load, and upsizes the wire if needed so the fuse always protects it. Fuses belong as close to the source as practical (ABYC calls for within 7 in / 18 cm). These are planning estimates, so the final design should be checked against ABYC E-11, NEC, ISO 10133, the FIA rules or your OEM spec.
